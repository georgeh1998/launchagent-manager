# launchagent-manager 実装計画

## 目標
`~/Library/LaunchAgents/*.plist` を一覧・詳細表示・追加・編集・削除・有効/無効切替・今すぐ実行できる Mac 用デスクトップアプリを Tauri v2 + React + TypeScript で作る。外部副作用（ファイル、launchctl、時刻）はすべて Rust の trait の裏に置き、フェイク実装でテストする。

- プロジェクトルート `/Users/george/Documents/georgeh1998/MAM` 直下に作る（既存コードなし）
- node 22.12 / npm 10.9 / rustc 1.99 / macOS 26.3 / uid 501 / `/bin/bash` 3.2.57
- `@tauri-apps/cli` 2.12.1、`@tauri-apps/api` 2.12.2、`plist` crate 1.10.1、`@digital-go-jp/design-tokens` 2.0.1

|---|---|
| アプリ名 / productName | `launchagent-manager` / `LaunchAgent Manager` |
| identifier | `dev.georgeh.launchagent-manager` |
| App Support | `~/Library/Application Support/launchagent-manager/`（`$HOME` から自前で組み立て） |

| 無効化 / 有効化 | 無効化 = `bootout` → `disable`。有効化 = `enable` →（未 loaded なら）`bootstrap` |
| 追加 | 書き込み → `enable` → `bootstrap`。bootstrap 失敗で plist 削除 |
| 編集 | 旧バイト列保持。失敗時は書き戻し + 旧ジョブ再 bootstrap（ベストエフォート、`rolledBack`）。無効状態のジョブは bootstrap しない。Label 変更時は disable を引き継ぐ |
| 削除 | `bootout` → plist 削除。ログ・記録・override DB は触らない |
| 未登録 bootout | 終了コード 3/113 または stderr に `No such process`/`Could not find` → 成功扱い |
| 原子的書き込み | 同ディレクトリ `.<name>.tmp-<millis>` → `/usr/bin/plutil -lint <tmp>` → rename。lint 失敗で tmp 削除しエラー |
| Label ルール | `[A-Za-z0-9._-]+`、200文字以内、先頭 `.` 不可。重複は大文字小文字無視 |
| ジョブ ID | フロント⇔Rust はファイル名（`com.x.plist`）。`/` 無し・先頭 `.` 無し・`.plist` 終わり・LaunchAgents 直下を検証 |
| 一覧対象 | `.plist` の通常ファイルのみ（隠し・ディレクトリ・`.DS_Store` 除外）。解析不可はエラー行 |
| 並び | displayName 大文字小文字無視の昇順 |
| 絞り込み | label・ファイル名の大文字小文字無視部分一致（フロント） |
| 曜日 | 内部 0–6（0=日）。plist の 7 は 0。表示順 月火水木金土日 |
| スケジュール→plist | 毎日・毎月・曜日1つの毎週は辞書。複数曜日は辞書配列（Weekday 昇順）。間隔は `StartInterval`（分×60 / 時間×3600） |

| 時刻表示 | `HH:MM` ゼロ埋め |
| フォールバック | `月=*, 日=1, 時=9, 分=0`。曜日は値があるときだけ `日=` の後に `曜日=月` |

| ダイアログ | `<dialog>` 不使用。`role="dialog" aria-modal="true"` 自作 |
| フォント | Noto Sans JP 非同梱。`--font-family-sans` のフォールバック |
| Rust 純粋ロジック | `src-tauri/src/domain/`（tauri 非依存） |
| コマンドパス | `/bin/launchctl`、`/usr/bin/plutil` |

## データ形式

### 実行記録 JSON
```json
{"version":1,"label":"com.georgeh.backup","started_at":"2026-10-09T00:00:00Z","finished_at":"2026-10-09T00:00:05Z","exit_code":0,"pid":12345}
```
- 開始時 `finished_at:null, exit_code:null` で書き、終了時に上書き（tmp→mv）。UTC。pid はラッパー PID。コマンドは記録しない
- 判定: exit 0 → 成功、≠0 → 失敗、finished null → 実行中（または中断）、ファイル無し → 未実行、壊れ → 読み取り不可

### ラッパースクリプト全文（`domain/wrapper.rs` の `pub const WRAPPER_SCRIPT`）
```bash
#!/bin/bash
# launchagent-manager wrapper v1 (generated by launchagent-manager; do not edit)
# usage: run-job.sh <label> <command>
set -u

if [ "$#" -lt 2 ]; then
  echo "usage: $0 <label> <command>" >&2
  exit 64
fi

label="$1"
cmd="$2"

case "$label" in
  ''|.*|*[!A-Za-z0-9._-]*)
    echo "run-job.sh: invalid label: $label" >&2
    exit 64
    ;;
esac

base_dir="$(cd "$(dirname "$0")/.." 2>/dev/null && pwd -P)"
runs_dir="$base_dir/runs"
record="$runs_dir/$label.json"
mkdir -p "$runs_dir" 2>/dev/null

now_utc() {
  date -u +%Y-%m-%dT%H:%M:%SZ
}

# $1: started_at, $2: finished_at (JSON value), $3: exit_code (JSON value)
write_record() {
  tmp="$record.tmp.$$"
  if printf '{"version":1,"label":"%s","started_at":"%s","finished_at":%s,"exit_code":%s,"pid":%s}\n' \
      "$label" "$1" "$2" "$3" "$$" > "$tmp" 2>/dev/null; then
    mv -f "$tmp" "$record" 2>/dev/null || rm -f "$tmp" 2>/dev/null
  fi
  return 0
}

started="$(now_utc)"
write_record "$started" null null

/bin/bash -c "$cmd"
rc=$?

finished="$(now_utc)"
write_record "$started" "\"$finished\"" "$rc"

exit "$rc"
```
